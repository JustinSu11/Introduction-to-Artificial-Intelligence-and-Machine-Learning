# 4.2 Tree-Based Methods I
*AAI-501 · Week 4 · cross-checked against the transcript*

**One line:** For **tabular data**, **tree-based methods** (especially
boosted trees like XGBoost) are state-of-the-art. Deep learning
wins on **complex** data (images, text).

**Hook:** Deep learning = images and language. Trees = Excel
sheets.

## Complex vs tabular data
| | Complex data | Tabular data |
|---|---|---|
| Structure | **Spatial** or **sequential** correlations, **hierarchical features** | Fits an Excel sheet: well-defined columns |
| Examples | Image of a car (headlights, windshield, license plate; edges -> shapes -> car). Text (LLMs) | Student ID, name, favorite food, meal plan, age |
| Best method | **Deep learning** (nothing comes close) | **Tree-based methods** (still rules corporate data) |

## Evidence trees win on tabular data
- Paper: **"Tabular Data: Deep Learning is Not All You Need":**
  **XGBoost can outperform deep learning** on tabular data.
- A **2022** study: tree-based models still state-of-the-art for
  **medium-sized data (~10,000 points).**
- **Francois Chollet (2019, Kaggle):** top submissions mixed
  TensorFlow/Keras (deep learning) with **XGBoost, Random Forest,
  LightGBM** (trees).
- Chollet (2021): **2016 to 2020**, the ML industry was
  dominated by **deep learning and gradient boosted trees.**
  Boosted trees for **structured data**, deep learning for
  **perceptual problems.** "The two techniques you should be most
  familiar with."

## What is a decision tree
- Multiple **branching decision rules** from a start to an
  **outcome prediction.**
- **Split** = an if-statement on **one variable.**
- **Leaf node (terminal node)** = final outcome (a class or a
  number).

**Example:** what to wear?
- Temperature < 15 C? If **yes:** is it raining? Rain -> **umbrella**,
  no rain -> **sweater.**
- If **no** (>= 15 C): is it sunny? Sun -> **T-shirt**, no sun ->
  **sweater.**
- 3 splits.

### Two types
| Type | Predicts |
|---|---|
| **Regression tree** | A **number** (e.g., home price) |
| **Classification tree** | A **class** (binary or multi-class) |

## Decision boundaries
- Regression: fit a function to the points.
- Classification: find the **decision boundary** separating
  classes. Example: borrower default vs repay using **income and
  employment duration.**
- Trees use boundaries for **both** tasks.

**Textbook example (baseball salary):**
- Splits: **Years < 4.5**, then for the rest **Hits < 117.5.**
- This cuts the Years-by-Hits plane into **3 regions (R1, R2,
  R3).**
- Each region's prediction = the **average** of observations in it
  (regression) or the **most common class** (classification).

**Key point:** every split uses **just one variable**, so the
boundary is made of **lines parallel to the feature axes.** Enough
splits can approximate a complicated curve.

## When NOT to use a tree
- If the true boundary is **linear**, a tree struggles (it needs
  a staircase of axis-parallel cuts). **Logistic or linear
  regression** fits it easily.
- If the boundary is **complex**, trees beat linear models.
- Rule: suspect a linear boundary -> use a linear model.
