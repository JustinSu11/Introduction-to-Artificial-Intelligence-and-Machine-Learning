# 1.1 What Is AI?
*AAI-501 · Read time: 2 min*

**One line:** AI is building and studying **agents** that
**act rationally** in an environment.

## Definition
AI = the **study** (understand intelligence) and
**construction** (build it) of computational agents that
act intelligently.

## Agent
Anything that can **perceive** its environment and
**act** on it.

**Flow:** Environment -> sensors -> agent decides ->
actuators/effectors -> back to environment.
**Hook:** Input -> think -> output.

## 4 ways to define "intelligent"
| | Human | Rational |
|---|---|---|
| **Thinking** | think like a human | think rationally |
| **Acting** | act like a human | **act rationally** (AI's focus) |

- Humans are often irrational (emotions, tired, sleepy).
  So AI targets **rationality**, not mimicry.
- **Rational** = pick the action that maximizes the
  **expected outcome given current information.**

**Catch:** rational does not mean always wins.
Picard: *"It is possible to commit no mistakes and still
lose."* Example: skipping Bitcoin in 2012 was rational
with the info available.

## Physical vs digital agents
- **Embodied AI:** has a physical body (delivery robot).
- **Software agent / bot:** digital only (web crawler).
- "Agentic AI" today usually means **digital** agents.
- Agents don't have to be physical.

## Applications
| Area | Examples |
|---|---|
| **Decision-making** | diagnosis (tumor on CT), forecasting, route/travel planning |
| **Computer vision** | object detection, quality control, handwriting recognition (USPS mail sorting) |
| **Robotics** | self-driving cars, manufacturing, humanoids |
| **NLP** | ChatGPT, Google Translate, talking to humanoids |

**Why NLP matters:** it makes AI usable by everyone
through plain language.
