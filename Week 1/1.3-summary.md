# 1.3 AI Agents and Their Environment
*AAI-501 · Read time: 3 min*

**One line:** An agent decides using 5 factors, runs on a
body + controller, and you design it by choosing across
**10 dimensions**. Pick what fits the task and budget,
not the most complex.

**Running example:** a lab delivery robot (coffee, mail,
supplies).

## Agent basics
- Agent = perceives (sensors) + acts (actuators).
- **Rational** = maximize expected outcome given the
  information so far.

## 5 factors in an agent's decision
**Hook: A-G-P-S-P**
1. **A**bilities: what it can do (move, pick up,
   avoid obstacles)
2. **G**oals/preferences: what it wants (coffee by 9 AM)
3. **P**rior knowledge: what it knows (lab map, physics)
4. **S**timuli: what it senses now (slippery floor,
   people nearby)
5. **P**ast experiences: what it has seen (real battery
   range, carrying capacity)

## Inside the agent: body + controller
- **Body:** turns stimuli into percepts, and commands
  into actions. Digital agents have one too (e.g., an
  API endpoint).
- **Controller:** the brain. Takes percepts + memory,
  decides the command, **updates memory.** ML algorithms
  live here.
- **Belief state:** everything the agent remembers from
  before (facts, past locations, goal progress).
- The controller works **across time steps**: each step
  passes info forward.

**Key point:** an ML model (like a regression) is **not**
an agent. It's a piece of the controller.

## Design space: 10 dimensions
Memory aid: **M**any **P**lans **R**arely **C**ompute
**L**ike **S**mart **E**ngineers **P**redict **N**ovel
**I**nteractions

| # | Dimension | Question | Options |
|---|---|---|---|
| 1 | **Modularity** | Break thinking into pieces? | flat, modular, hierarchical |
| 2 | **Planning horizon** | How far ahead? | none, finite, indefinite, infinite |
| 3 | **Representation** | How to describe the world? | states, features, relations |
| 4 | **Computational limits** | How long can I think? | perfect vs **bounded** rationality |
| 5 | **Learning** | Where does knowledge come from? | given (rules) vs learned (ML) |
| 6 | **Sensing uncertainty** | Can I see everything? | fully vs partially observable |
| 7 | **Effect uncertainty** | Do I know what my action causes? | deterministic vs stochastic |
| 8 | **Preference** | What is success? | goal vs complex trade-offs |
| 9 | **Number of agents** | Who else is in my world? | single, adversaries, multiple |
| 10 | **Interactivity** | When do I think? | online (live) vs offline |

## Quick examples (robot)
- **Horizon:** staying upright = infinite. Deliver coffee
  to Dave, time unknown = indefinite. Battery (3 hrs) =
  finite. React to bug alerts = none.
- **Representation:** states = every snapshot (explodes
  fast). Features compress it (30 Boolean features ~
  1 billion states). Relations = connections (LinkedIn).
  Only represent what's relevant.
- **Bounded rationality:** a perfect path around Dave is
  useless if the collision already happened.
- **Observability:** corridor corner = partial. Security
  booth with all cameras = full.
- **Deterministic vs stochastic:** dominoes vs stock
  trading.
- **Agent or not?** Ask: do I need to account for this
  entity's reasoning? Another robot or a scientist: yes.
  A bird outside: no.
- **Adversary vs multiple agents:** zero-sum (you or
  them) vs just planning around others.
- **Online vs offline:** real-time updates vs updating
  while docked overnight. Online is powerful but costly.

## Practical note
You rarely start from scratch. Use a **template** design
space (web crawler, chatbot, self-driving car).

## 30-second recall
List the 5 decision factors. Say what the body and
controller do. Name as many of the 10 dimensions as you
can.
