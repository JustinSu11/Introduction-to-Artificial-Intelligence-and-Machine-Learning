# Lab 1.5: Build Your First AI Agent (LangChain)
*AAI-501 · Week 1 Lab · cross-checked against the transcript*

**One line:** Use **LangChain** + **Gemini** to build an
agent whose brain is an LLM and whose only tool is
**Wikipedia.**

## What is LangChain?
A **framework to help developers build LLM-powered
applications**: a powerful toolkit. Capabilities:
1. **Retrieval-augmented generation (RAG)**
2. **Memory management**
3. **Chaining together LLM calls and logic**
4. **Building agents**

This lab: **LangChain + Google Gemini** = Gemini is "the
brain, the **controller**" of an agent that can **query
Wikipedia based on user prompts.**

**Hook:** LangChain = the toolbox. Gemini = the brain.

## The build: 4 steps
1. **Make the Wikipedia tool** (**two lines**): a **direct
   import to access Wikipedia's API**, plus a **wrapper
   utility** around the Wikipedia tool itself.
2. **Make the LLM:** initialize **Gemini** as the LLM option
   (lab used **"Gemini 1.5 latest"**), `temperature=0`, API key
   passed as an environment variable.
3. **Make the agent** (one init): you supply
   - **the tool list** ("a list of my effectors")
   - **the LLM brain**
   - **the agent type:** `zero-shot-react-description`
     (a specific type that defines how the agent thinks and
     processes; "don't worry too much about it")
4. **Run it** with `verbose=True`.

**Hook:** Tool -> Brain -> Agent -> Ask.

## Key terms
- **Temperature = 0:** you don't want much **tolerance for
  stochasticity** (randomness): more consistent answers.
  (Lecturer: "we'll talk later about what that means.")
- **Zero-shot ReAct description:** the agent reasons, picks a
  tool, reads the result, and repeats, with no examples given
  up front.
- **Verbose = True:** shows the **chain of thought**, how the
  agent reached its decision. "Like opening up the
  controller."

## Example run
Prompt: *"What is the capital of France?"*
1. **Thought:** "I need to find the capital city of France.
   Wikipedia is a good resource" (lecturer joke: it's the only
   tool, of course it is).
2. **Action / Action input:** query Wikipedia.
3. **Observation:** the tool returns **a list of capitals of
   France from a specific page.**
4. **Thought:** "a chronological list... **Paris since its
   liberation in 1944.** I now know the final answer."
5. **Final answer:** **Paris.**

Pattern: **Thought -> Action -> Observation -> Final Answer.**
