# Lab 1.5: Build Your First AI Agent (LangChain)
*AAI-501 · Read time: 3 min*

**One line:** Use **LangChain** + **Gemini** to build an
agent whose brain is an LLM and whose only tool is
**Wikipedia.**

## What is LangChain?
A Python framework for building LLM-powered apps.
It gives you: retrieval-augmented generation (RAG),
memory, chaining LLM calls and logic, and **agents.**

**Hook:** LangChain = the toolbox. Gemini = the brain.

## Map it to Lecture 1.3
| Agent idea | In this lab |
|---|---|
| Controller (brain) | **Gemini** LLM |
| Actuator / effector | **Wikipedia tool** |
| Percept | the user's prompt + tool results |
| Belief/reasoning | the visible chain of thought |

## Setup
- **Where:** Google Colab (easy package management).
  Jupyter notebooks also work.
- **Install:** `langchain`, `wikipedia`,
  `google-generativeai`, `langchain-community`,
  `langchain-google-genai`
- **Prerequisite:** get a **Gemini API key** and store it
  in **Colab Secrets** (watch the required video first).
  Load it into an environment variable. Never hard-code
  the key.
- Expect lots of `import` lines. LangChain has far more
  features than you'll use.

## The build: 4 steps
1. **Make the tool:** Wikipedia API wrapper + a tool
   built on it.
2. **Make the LLM:** Gemini (lab used "1.5 latest"),
   `temperature=0` (low randomness), API key from the
   environment.
3. **Make the agent:** give it the tool list, the LLM,
   and the agent type
   `zero-shot-react-description`.
4. **Run it** with `verbose=True` to see its thinking.

**Hook:** Tool -> Brain -> Agent -> Ask.

## Key terms
- **Temperature = 0:** minimal randomness, more
  consistent answers.
- **Zero-shot ReAct:** the agent reasons, picks a tool,
  reads the result, and repeats, with no examples
  given up front. (Lab: "don't worry about the details.")
- **Verbose = True:** prints the chain of thought. Like
  opening up the controller.

## Example run
Prompt: *"What is the capital of France?"*
1. **Thought:** I need the capital of France. Wikipedia
   is a good source (it's the only tool).
2. **Action:** query Wikipedia.
3. **Observation:** a list of France's capitals.
4. **Thought:** Paris has been the capital since 1944.
5. **Final answer:** **Paris.**

Pattern: **Thought -> Action -> Observation -> Answer.**
