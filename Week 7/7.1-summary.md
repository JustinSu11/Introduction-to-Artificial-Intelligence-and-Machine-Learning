# 7.1 Reinforcement Learning
*AAI-501 · Week 7 · cross-checked against the transcript*

**One line:** **Reinforcement learning (RL)** = an **agent** learns by
**trial and error** to maximize **cumulative reward.** No labeled
answers, only reward signals. The math frame is the **Markov
Decision Process (MDP).**

**Where it fits:** supervised = labeled examples, unsupervised =
find patterns, **RL = get reward signals.** Part 2 of the "agents"
topic from earlier in the course.

# LAYER 1: LEARN IT

## The big idea
Many real tasks have **no answer key,** just feedback on how you're
doing: learning **violin, driving, walking.** RL is the machine
version. The lecturer calls it the most common ML at the
**software-hardware interface** (robots).

**Hook:** training a **puppy** with treats. It never sees the
rulebook, only "good boy / bad boy."

Examples: **AlphaGo** (reward = win), **self-driving car** (speed
relative to other cars, smoothness), **robot learning to walk,**
personalized education, game playing.

## 1) Agent, state, action, reward, policy
| Term | Meaning | Vacuum-robot example |
|---|---|---|
| **State s(t)** | what the agent knows of the world now | which squares are clean/dirty, time, battery |
| **Action a(t)** | the choice | move left/right, return to dock |
| **Policy** | the rule that picks actions (the formal "controller") | |
| **Reward** | a **number** after acting | e.g. inverse of % squares still dirty |
| **New state** | where it lands | |
**Loop:** state -> policy picks action -> reward + new state.
The **agent-environment interface** = what it can see
(observations), do (actions), and get (rewards).

Earlier-course links: **belief state** = memory of past steps;
**controller** = decides what to do (the policy is its formal
version).

**Coin game example:** state space = **(x, y), fuel, coin 1-4
collected (booleans).** Hard part: moving down gets Coin 3 but
costs fuel, so how do you judge it? -> need **cumulative reward.**

## 2) Markov chains
- A **Markov chain** = states + **transition probabilities.**
- **Markov property:** where you go next depends **only on the
  current state** (and the probabilities), **not** on history.
- Lecture example: from E, go to A with **0.7** or stay in E with
  **0.3.**
- **Why RL uses it:** (1) **computationally tractable** (no need
  to store all history; state space explodes otherwise), (2)
  gives **elegant math** for finding the best action.

## 3) MDP: five parts
| Symbol | Part | Meaning |
|---|---|---|
| **S** | states | situations of the environment |
| **A** | actions | choices (may depend on the state) |
| **P** | transition probability | P(s' given s, a) |
| **R** | reward function | reward for s, a, s' |
| **gamma** | discount factor | 0 to 1: immediate vs future |
**gamma = 1:** value future like now. **gamma = 0:** ignore the
future. In between: future matters, but less.
Trajectory: s0 -a0-> s1 (reward r0), s1 -a1-> s2 (reward r1)...
**Fully observable = MDP. Partially observable = POMDP.** This
course = **MDPs only.**

**Hook:** an MDP = **a board game's rulebook:** squares, moves,
dice odds, points, and how much you care about later turns.

## 4) Sam's weekend (textbook example)
**States:** healthy, sick. **Actions:** relax, party.
**Transitions (lecture, qualitative):**
- Healthy + relax -> **high** chance of staying healthy.
- Healthy + party -> still **> 50%** healthy, but lower.
- Sick + relax -> **50/50** to recover.
- Sick + party -> **low** chance of recovering.
**Rewards (lecture):** healthy+relax **7,** healthy+party **10,**
sick+relax **0,** sick+party "a little" (unspecified).

## 5) Three ways to add up rewards over time
1. **Total** reward (works for finite problems).
2. **Average** reward.
3. **Discounted** reward: later rewards count less. **Most popular
   in RL,** tunable with gamma; **gamma = 1 gives plain total.**
   Matches how humans think (today > tomorrow).

## 6) Policies
A **policy pi(a given s)** = probability of choosing action a in
state s.
| Policy | Rule |
|---|---|
| **Random** | every action equally likely |
| **Greedy** | always pick the action with the highest **Q(s, a)** (best reward guess) |
| **Epsilon-greedy** | best action **1 - epsilon** of the time (e.g. **80%**), a random one **epsilon** (e.g. **20%**) |
**Q(s, a)** = best guess of reward for doing action a from state s
(more in 7.2).

**Sam's policies:** 2 states x 2 actions = **4:** always relax,
always party, relax if healthy/party if sick, party if
healthy/relax if sick (**mutually exclusive and collectively
exhaustive,** the lecturer leaves the proof as an exercise).

## 7) Explore vs exploit
- **Exploit** = take the best known option. **Explore** = try
  something new.
- **Greedy** can miss better options (always the favorite
  restaurant, never the new one next door).
- **Only exploring** wastes time on bad options.
- **Epsilon-greedy** balances both.

## 8) Multi-armed bandit (preview of 7.4)
A slot machine = **one-armed bandit.** **K slot machines** with
**unknown payout distributions:** pick which arm to pull to
maximize total reward. Real uses: **clinical trials, online
advertising, recommendations** (Facebook, Netflix).

## Big picture recap
- RL = **act, get reward, adjust.** No labels.
- **MDP = S, A, P, R, gamma.** Markov = only the present matters.
- **Policy** chooses actions; **discounted reward** is the usual
  goal.
- **Explore vs exploit** is the core tension; epsilon-greedy
  handles it.

# LAYER 2: QUIZ REFERENCE

- ML types: **supervised, unsupervised, reinforcement.** RL has
  **reward signals,** not labels.
- RL (definition): "an agent learning through trial and error to
  maximize a cumulative reward."
- Agents: **perception, reasoning, action;** percepts include
  reward. **Belief states, controllers** (earlier).
- Vacuum-robot state/action/reward example; **S-sub-t, A-sub-t.**
- **Policy** = formalization of the controller.
- **Markov chain, Markov property;** reasons: tractability,
  elegant math.
- **MDP components:** S, A, P, R, gamma (five).
- **MDP vs POMDP:** fully vs partially observable.
- Sam: states healthy/sick, actions relax/party, rewards 7, 10, 0.
- Reward models: total, average, **discounted.**
- gamma = 1: total; gamma = 0: only immediate.
- Policy pi(a given s); random, greedy, epsilon-greedy.
- **Q-value:** best guess of the reward for action a from state s.
- **Explore-exploit** tradeoff; **multi-armed bandit** (K arms,
  unknown distributions; clinical trials, ads, recommenders).
- Self-driving, AlphaGo, robot walking, violin, driving.
