# 7.2 Rewards and Model-based RL
*AAI-501 · Week 7 · cross-checked against the transcript*

**One line:** To pick good actions you need to **estimate value.**
**V** scores states, **Q** scores actions. The **Bellman equations**
define the **best** values, and **dynamic programming** solves them
**if you know the world model** (**model-based RL**).

**Where it fits:** 7.1 gave policies that need Q(s, a). 7.2 says how
to compute it when P and R are known. 7.3 handles when they aren't.

# LAYER 1: LEARN IT

## The big idea
A policy (greedy, epsilon-greedy) is only as good as its **reward
estimates.** If you **know the rules of the world** (transition
probabilities and rewards), you can calculate the values by
repeated refinement. "RL actually becomes kind of easy."

**Hook:** **GPS with the full map.** Know every road and traffic
time and you can plan the best route by sweeping the map until the
estimates stop changing.

## 1) Two value functions
| Name | Symbol | Meaning |
|---|---|---|
| **State value** | **V-pi(s)** | expected **return** starting in s and following policy **pi** |
| **Action value (Q-value)** | **Q-pi(s, a)** | expected return starting in s, taking action **a,** then following pi |
- Q focuses on **the action ahead;** V on the **whole path.**
- **V(s) = Q(s, a)** when a is the action pi would pick.

## 2) Optimal values
**V*(s)** and **Q*(s, a)** = the best possible values. **If you find
either, the problem is solved:** in each state pick the action with
the best **Q*.**

## 3) Bellman optimality equations (in words)
**For V*:** V*(s) = **max over actions** of the **sum over next
states s'** of **P(s' given s, a) x [ R(s, a, s') + gamma x V*(s') ]**
= "choose the action with the best **immediate reward + discounted
long-term value.**"
**For Q*:** Q*(s, a) = sum over s' of P x [ R + gamma x **max over
a' of Q*(s', a')** ].
Both contain **MDP terms:** P, R, gamma.

**Trap:** V* appears on **both sides.** Looks circular, but it's
**recursive,** which is the trick.

## 4) Dynamic programming (Richard Bellman, 1950s)
**Idea:** break a big problem into **sub-problems,** solve
recursively, **reuse** solutions.
**Iterative update (value iteration):**
1. Start with an **initial guess** for V (e.g. all zeros).
2. For every state s: compute the right side using the **current**
   V of next states, P and R. That's the new V.
3. Repeat (**k = 1, 2, 3...**) until values stop changing
   (**convergence**).

**Hook:** like **epochs in deep learning:** rounds of refinement.

### Tiny worked example (my addition, using 7.1's Sam, verified)
With gamma = 0.9 and my made-up probabilities, repeating this
update converges to **V(healthy) = 67.1, V(sick) = 54.9,** and the
best policy is **party when healthy, relax when sick.**

## 5) Model-based vs model-free
The question: **can we build a complete model (P and R)?**
| | Model-based | Model-free (7.3) |
|---|---|---|
| Model of world | **yes** (P and R known/built) | no |
| Data | **efficient** (little data) | **inefficient** (lots) |
| Cost | **computational expense, model bias** risk (did you build P and R right?) | simple, **robust** in complex worlds |
| Uses | **robotics, industrial processes, healthcare** (small, known worlds, e.g. a chemical mixer) | **recommenders, video games,** some robotics |
**Self-driving cars:** too complex to model fully -> learn from
experience.

## Big picture recap
- **V** (state) and **Q** (action) estimate return.
- **V*/Q*** = best; the **Bellman equations** define them
  recursively.
- With known P and R, **dynamic programming** iterates to
  convergence.
- Model-based = data-efficient but needs an accurate model.

# LAYER 2: QUIZ REFERENCE

- A good policy depends on a good **estimate of reward** for an
  action (greedy, epsilon-greedy use **Q(s, a)**).
- **State value function V-pi(s):** expected return from s
  following pi (e.g. "always turn left").
- **Action value function Q-pi(s, a) (Q-value):** expected return
  from s taking a, then following pi.
- **V* and Q*:** best possible state/action value functions; if
  found, "our problem is solved."
- **Bellman equation (V*):** max over actions of sum over s' of
  P(s' given s, a) [R(s, a, s') + gamma V*(s')].
- **Bellman equation (Q*):** P, R, and **gamma x max over next
  actions** of Q*(s', a').
- Equations are **recursive** -> **dynamic programming (dynamic
  planning),** invented by **Richard Bellman in the 1950s.**
- Iterative update: need P and R functions; start with initial V;
  increase **k** until **convergence.**
- **Model-based RL:** complete model of the environment; learn
  from the model; **data efficient;** downside **computational
  expense, model bias;** uses **robotics, industrial processes,
  healthcare.**
- **Model-free RL:** simpler, more robust in complex environments;
  **data inefficient;** recommender systems, video games, some
  robotics.
- Self-driving car example for model-free.

## Answers
1. V = value of a state under a policy; Q = value of taking a
   specific action first, then following the policy.
2. Best possible values; pick the action with the best Q*.
3. Pick the action maximizing immediate reward plus discounted
   value of where you land, averaged over transitions.
4. It's recursive, so you can iterate from a guess to the answer.
5. Guess V; update every state from P, R, gamma and current V;
   repeat until convergence.
6. P (transitions) and R (rewards).
7. Model-based: data-efficient, but costly and prone to model
   bias. Model-free: robust, simple, but needs a lot of data.
8. Too many variables to build a full model.
9. Model bias: the values and policy will be wrong.
