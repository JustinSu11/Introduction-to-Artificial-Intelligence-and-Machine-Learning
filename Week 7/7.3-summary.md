# 7.3 Model-free RL (Q-learning)
*AAI-501 · Week 7 · cross-checked against the transcript*

**One line:** With **no model of the world,** the agent learns **Q
values from experience.** Each step nudges one cell of a **Q-table**
toward a better guess using the **temporal-difference (TD) error.**
That is **Q-learning.**

**Where it fits:** 7.2 needed P and R. Here we skip them. Q-learning
supplies the Q estimates your policy (greedy, epsilon-greedy) needs.

---
# LAYER 1: LEARN IT

## The big idea
We can't know **Q*,** but we can **estimate it** from every
experience: "I was in s, did a, got reward r, landed in s'." Update
your guess **a little** toward what you just saw.

**Hook:** a **running average** that learns: new belief = old
belief + a small step toward the surprise.

## 1) The update idea from a moving average
New estimate = **old estimate + learning rate x (new observation -
old estimate).**
The bracket is the **temporal difference (TD) error:** how wrong
the old guess was. The learning rate (**alpha**) says how much to
trust the new observation.
"This is a very common theme": same pattern as **forecasting and
gradient descent.**

## 2) The Q-learning update
**Q(s, a) <- Q(s, a) + alpha x [ r + gamma x max over a' of Q(s', a')
- Q(s, a) ]**
- **r + gamma x max Q(s', a')** = **target** = reward now + best
  discounted future (our new best guess).
- **target - old Q** = **TD error.**
- **alpha** = learning rate.
Data point = **(s, a, r, s').** It is an **online algorithm** (each
new data point triggers an update).

## 3) The Q-table
A **lookup table** with one value per **state-action pair.**
Randomly initialize it (or use prior knowledge), update **one cell
per step,** repeat until it **converges** (policy stops changing).

### Worked example (verified)
2 states (A, B), 2 actions (left, right), **gamma = 0.9,
alpha = 0.5.**
Experience: **in A, move right, reward r = 1, land in B.**
Q-table before: Q(A, right) = **0.8;** in B the best value is
**max = 4.0** (left 4.0, right 2.5 per the lecture).
| Step | Calc | Result |
|---|---|---|
| Discounted future | 0.9 x 4.0 | **3.6** |
| **Target** | 1 + 3.6 | **4.6** |
| **TD error** | 4.6 - 0.8 | **3.8** |
| **New Q(A, right)** | 0.8 + 0.5 x 3.8 | **2.7** |
Only the **(A, right)** cell changes.

**Trap:** you update **one cell,** the one you just acted on, not
the whole table.

## 4) When tables are too big
Self-driving cars or robots = far too many state-action pairs.
Three neural-network options (just named, not taught):
| Method | Idea |
|---|---|
| **Deep Q-network (DQN)** | neural net takes the **state,** outputs **Q for every action** |
| **Policy gradient** | skip Q, **approximate the policy directly** |
| **Actor-critic** | networks for **both** policy and value, combined |

## 5) The policy is still in charge
Q-learning (or DP) only gives the policy **better reward
estimates.** The **policy** (random, greedy, epsilon-greedy) still
controls the agent.

## Big picture recap
- Model-free = learn from experience, not from P and R.
- **Q-learning** = TD-error updates of one Q-table cell at a time.
- **Table breaks at scale** -> DQN, policy gradient, actor-critic.
- Policy picks actions; Q-learning improves its information.

# LAYER 2: QUIZ REFERENCE

- Model-free: no model of the environment; **learns from
  experience;** simpler and more robust; **data-inefficient;** used
  in recommender systems, video games, robotics.
- Q-learning: iteratively update to approximate **Q*;**
  **Q-star unknown, estimate with observations.**
- Moving-average analogy: A(k) = A(k-1) + learning parameter x
  **TD error** (new observation - old prediction).
- TD error = "how off our old prediction was from the new
  observation."
- Data point: **s, a, r, s'.**
- Target = **r + gamma max Q(s', a').**
- Steps: randomly initialize Q; observe reward and next state;
  compute a better guess; update **a single Q(s, a)**; repeat.
- Q-learning is **online.**
- **Q-table** = lookup table of every state-action pair; converges.
- Example numbers: gamma 0.9, alpha 0.5, r = 1, old Q 0.8, max Q(B)
  4.0 -> 3.6 -> 4.6 -> 3.8 -> **2.7.**
- Scaling: **DQN, policy gradient, actor-critic;** all use neural
  networks.
- Policy still controls the agent (random, greedy, epsilon-greedy).
