Presentation 7.2: Rewards & Model-based RL
AudioLinks to an external site. (12:25)
Summary
Focuses on policies and how they depend on reward estimation.
Introduces state value functions (V) and action value functions (Q).
Presents optimal values (V* and Q*) using Bellman equations.
Explains dynamic programming for solving MDPs when models are known.
Contrasts model-based (data-efficient but costly) with model-free RL (robust but data-hungry).
