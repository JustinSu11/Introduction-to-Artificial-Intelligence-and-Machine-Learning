Summary
Machine learning teaches computers to learn from data when rules are unknown.
Three main types: supervised, unsupervised, and reinforcement learning.
Supervised learning predicts known targets using labeled data (e.g., classification, regression).
Key supervised models include linear regression and logistic regression.
Performance metrics vary: MSE/MAE for regression; accuracy, precision, recall, F1, ROC for classification.
