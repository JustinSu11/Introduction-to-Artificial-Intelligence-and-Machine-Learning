**One line:** **PuLP** lets you write an LP the way you'd write the
math: make a problem, add variables, add the objective, add
constraints, **solve**, check the **status**, read the values.

## Steps and code
```python
import pulp

# 1. Problem object (maximize; use pulp.LpMinimize to minimize)
lp501 = pulp.LpProblem("LP501", pulp.LpMaximize)

# 2. Variables: continuous, with lower bounds
x = pulp.LpVariable("X", lowBound=0, cat="Continuous")
y = pulp.LpVariable("Y", lowBound=2, cat="Continuous")
# cat="Integer" would make it a MIP variable

# 3. Objective: Z = 4x + 3y   (first expression added)
lp501 += 4 * x + 3 * y

# 4. Constraints (add with +=)
lp501 += 2 * y <= 25 - x
lp501 += 4 * y >= 2 * x - 8
lp501 += y <= 2 * x - 5

# 5. Solve and read
lp501.solve()
print(pulp.LpStatus[lp501.status])   # Optimal
print(x.value(), y.value())          # 14.5  5.25
```
*(Object name "LP 501" in the transcript = `lp501` here. Exact
variable names are my reconstruction from the narration.)*

## What the lab sets up
- **Maximize** Z = 4X + 3Y.
- **Constraints:** 2Y <= 25 - X; 4Y >= 2X - 8; Y <= 2X - 5.
- **Bounds:** X >= 0, Y >= 2.
- **Result:** **Optimal at X = 14.5, Y = 5.25.**
  Z = 4(14.5) + 3(5.25) = **73.75.** (Verified by running it.)
- Printing the problem object shows the objective, constraints,
  and variables. `lp501.variables()` gives direct access to the
  variables.

## 5 status codes
| Status | Meaning |
|---|---|
| **Not Solved** | Haven't found a solution yet |
| **Optimal** | Found the best solution (this lab) |
| **Infeasible** | **No** point satisfies all constraints |
| **Unbounded** | Maximizing goes to **infinity** (missing a limit) |
| **Undefined** | An optimal solution may exist but **wasn't found** |
*(PuLP integer codes: 0 / 1 / -1 / -2 / -3.)*
