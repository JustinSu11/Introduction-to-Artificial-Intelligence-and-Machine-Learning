# LAYER 1: LEARN IT

## The big idea
Logistic regression draws a **straight** boundary. A network of
them draws a **curved** one, but only because of the **activation
functions** between layers. No activations = still just a line.

**Hook:** activations are **bends in a wire.** One wire = straight.
Many wires with bends = any curve.

## 1) Neuron = logistic regression
1. Inputs x1...xn, weights w1...wn, bias b.
2. **z = w·x + b** (weighted linear combination).
3. **Sigmoid(z)** -> output between 0 and 1.
Stacking neurons = "logistic regression on logistic regression
on logistic regression."

## 2) Why it becomes non-linear
- **One hidden layer, wide:** combines many linear boundaries,
  like a **spline.** Enough of them approximate **any** curve.
- **Deep (nested):** layer 2 = weights x sigmoid(layer 1) + bias.
  The sigmoid inside means it **can't collapse** to linear.
- **Remove the activations** and the nest of linear functions
  collapses to **one linear function** (plain linear model).

**Trap:** more layers without activations adds **nothing.**

## 3) The three activation functions
| Name | Shape | Range | Notes |
|---|---|---|---|
| **Sigmoid** | S curve | 0 to 1 | easy to understand (= logistic regression); **not centered at 0** -> less stable training |
| **tanh** | S curve, shifted | about -1 to 1 | **centered at 0:** "best of both worlds" |
| **ReLU** | 0 for x < 0, x for x > 0 | 0 to infinity | **kink at 0** breaks linearity; derivative = 1 |

## 4) Vanishing gradient (why not sigmoid/tanh deep inside)
Backprop **multiplies** by the activation's derivative at every
layer going back. Sigmoid's derivative is **at most 0.25.**
| Derivative | x itself 5 layers back |
|---|---|
| 0.25 | 0.25^5 = **0.00098** (lecture: "0.001") |
| 0.1 | 0.1^5 = **0.00001** |
Early layers get a **near-zero gradient** and stop learning.
**ReLU's derivative is 1** for positive inputs, so the gradient
survives.

**Hook:** a **whisper game** with 20 people: each one halves the
message, nothing reaches the first person.

### ReLU issues
- **Dead neuron:** if inputs stay negative, output and gradient
  are **0**, the neuron is "turned off."
- **Fix: Leaky ReLU:** scale negatives by a small factor
  (**1/10 or 1/100**) so the gradient isn't zero.
- Plain ReLU still works very well. "Sometimes you have to
  empirically test and see what works."
- **Rule for this course: hidden layers = ReLU.** The **input
  layer has no activation.**

## 5) Output layer: pick by task
| Task | Output neurons | Activation |
|---|---|---|
| **Regression** | **1** | **none** (just the linear value) |
| Regression, **positive only** (house price) | 1 | **ReLU** |
| **Binary** classification | **1** | **sigmoid** |
| **Multi-class** (K classes) | **K** | **softmax** |

### Softmax (worked example, verified)
**softmax(z_i) = e^(z_i) / sum of e^(z_j).** Turns K raw scores
into **probabilities that sum to 1.**
Scores dog 2, cat 4.3, pig 1.2, bear -3.1:
| Class | Score | Probability |
|---|---|---|
| dog | 2 | 0.0875 |
| **cat** | 4.3 | **0.8727** |
| pig | 1.2 | 0.0393 |
| bear | -3.1 | 0.0005 |
Biggest score -> biggest probability.
**Trap:** softmax keeps the **ranking** but exaggerates gaps.

## 6) Designing a network (decisions)
1. **Problem type** (classification / regression / other). Images
   -> **CNN**, sequences -> **RNN** (later lectures).
2. **Complexity:** harder problem = deeper/wider, but watch
   **overfitting.** Aim for a **happy medium** of depth and width.
3. **Data size:** bigger network needs more data. Little data ->
   simpler network.
4. **Compute:** complex = more GPUs ("only so many GPUs to go
   around").
5. **Experiment:** intuition often fails. Test hypotheses; build
   on literature.

### Hyperparameters
| Item | Advice |
|---|---|
| **Learning rate** | default **smaller/slower;** too high diverges, too low is slow |
| **Batch size** | batch, mini-batch, or stochastic GD: try combos |
| **Epochs** | full passes over data; use train/test plots to **stop early** |
| **Optimizer** | SGD, **Adam,** RMSprop |
| **Loss function** | "deep learning is supervised learning," make sure the loss answers your question |

## 7) When NOT to use deep learning
- **Try simpler models first:** interpretable, cheaper, and often
  as good or better on simple problems.
- Deep learning shines with a **massive training set** ("all
  published books") **or when interpretability doesn't matter.**

## Big picture recap
- Neuron = logistic regression; **activations make it non-linear.**
- Sigmoid/tanh **vanish** the gradient; **ReLU** fixes it.
- **Hidden = ReLU.** Output = none / sigmoid / softmax by task.
- Design = problem, size, data, compute, then **experiment.**

# LAYER 2: QUIZ REFERENCE

- Linear combination -> activation -> next layer; loss compares
  output to real value.
- Nested non-linear functions can't reduce to linear. "Wide or
  deep" both work to give a non-linear boundary.
- Three activations: **sigmoid, tanh (hyperbolic tangent), ReLU
  (rectified linear unit).**
- tanh = sigmoid "shifted," **centered around zero instead of
  0.5.**
- **Standardization:** inputs should be centered near zero and
  bounded; sigmoid is bounded 0-1 but not centered.
- **Sigmoid max derivative 0.25.**
- **Vanishing gradient:** gradients shrink the further back you go.
- **ReLU:** >0 returns the number; <0 returns 0; **derivative 1.**
- **Dead neuron problem;** **Leaky ReLU** (1/10 or 1/100).
- ReLU **nearly always** used for hidden layers.
- Output: regression = 1 node, no activation (ReLU if positive
  only); binary = 1 node + sigmoid; multi-class = K nodes +
  **softmax.**
- Softmax converts an output vector of K values into
  probabilities. Example classes: **cat, dog, pig, bear.**
- Lifecycle: data collection, design, train/validate, deploy.
- Architecture factors: problem, complexity, data size, compute,
  experimentation.
- Hyperparameters: learning rate, batch size (batch / mini-batch
  / SGD), epochs, optimizer (**SGD, Adam, RMSprop**), loss.
- **Don't always use deep learning.**

## Answers
1. Weighted sum then sigmoid = logistic regression.
2. Nested linear functions collapse into one linear function.
3. Sigmoid: not centered, vanishes. tanh: vanishes. ReLU: dead
   neurons.
4. Gradient is multiplied by <= 0.25 at each layer, so it shrinks
   exponentially going back.
5. Negative inputs give zero output and zero gradient; Leaky ReLU.
6. (a) 1 neuron, none (or ReLU if positive); (b) 1 neuron, sigmoid;
   (c) 4 neurons, softmax.
7. [0.5, 0.5] (equal scores -> equal probabilities).
8. Interpretable, cheap, often just as good.
9. Too high: diverges. Too low: slow convergence.
