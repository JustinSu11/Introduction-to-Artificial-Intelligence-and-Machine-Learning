# 6.1 Introduction to Deep Learning
*AAI-501 · Week 6 · cross-checked against the transcript*

**One line:** A **neural network** stacks lots of tiny "weighted-sum
+ activation" units (**neurons**) in **layers.** Trained with
**gradient descent + backpropagation,** it learns **non-linear
patterns and its own features** from messy data like images and text.

**Where it fits:** Weeks 1-5 were "traditional" ML (trees, boosting,
regression, time series). Now: deep learning, which dominates
**unstructured** data.

# LAYER 1: LEARN IT

## The big idea
Chollet's point: two methods dominate ML: **deep learning** and
**gradient-boosted trees.** Trees win on **structured/tabular**
data. Deep learning wins on **unstructured, complex** data (images,
language, signals, protein folding).

**Hook:** a **brain-inspired assembly line.** Each worker (neuron)
weighs inputs, decides, passes it on. Later workers see more
abstract things.

Timeline per lecture: deep learning proposed **1946** but exploded
in the last **10-15 years** (**AlexNet,** AlphaGo, transformers/GPT).
*(Lecture says AlexNet 2013; my addition: commonly dated 2012.)*

## 1) From a brain neuron to an artificial one
Brain: **dendrites** receive signals -> cell body/**axon**
transforms -> output (maybe, maybe modulated). *(Lecture: a grain-
of-rice piece of brain holds about 10-12,000 neurons with about
6,000 connections each.)*

**Artificial neuron (3 steps):**
1. **Inputs** x1, x2, x3.
2. **Amplify:** weighted sum **w1x1 + w2x2 + w3x3 + b** (bias =
   intercept). Example: 2x1 + 3x2 + 5x3.
3. **Activation** function (here **sigmoid**) -> output.

**One neuron with sigmoid = logistic regression.**

## 2) Why deep learning? (3 reasons)
| # | Reason | Plain meaning |
|---|---|---|
| 1 | **Non-linear boundaries** | can curve around dog vs cat, speech |
| 2 | **Automatic feature engineering** | neurons compute their own non-linear features; weights start **random**, useful ones strengthen, useless go toward zero (**interpretability cost:** hard to explain features) |
| 3 | **Hierarchical features** | layers build on layers: lines -> eye/nose -> faces (Tom Hanks) |

**Demand example:** price + shipping -> **affordability;** marketing
-> **awareness;** material + marketing + price -> **perceived
quality;** these three predict demand.

## 3) Architecture
- **Input layer:** loads the data.
- **Hidden layers:** the "magic": non-linear transforms, features.
  Often several or hundreds.
- **Output layer:** a **number** (regression) or **probability**
  (classification).

### Counting parameters (worked example, verified)
Parameters per layer = **inputs x neurons (weights) + neurons
(biases).**
| Layer | Weights | Biases | Total |
|---|---|---|---|
| 2 inputs -> 6 neurons | 12 | 6 | **18** |
| 6 -> 8 neurons | 48 | 8 | **56** |
| 8 -> 4 outputs | 32 | 4 | **36** |
| **Network** | | | **110** |
Small nets reach **hundreds of thousands to millions;** big
generative models **billions.**

## 4) Training
- Optimizer: **gradient descent,** usually **mini-batch** (not all
  data, not one point).
- Loss: **MSE** (regression) or **binary cross-entropy**
  (classification).
- **Epoch** = one full **forward + backward pass** over **all**
  training data.
- **Forward pass:** compute predictions and error.
- **Backward pass (backpropagation):** send the error back and
  update weights.

**Why backprop?** We need the gradient of the loss with respect to
**every weight,** but layers depend on each other. The **chain
rule** handles it.

### Backprop math in plain steps (single path)
Notation for layer L: **z(L) = w(L)·a(L-1) + b(L)**, **a(L) =
sigmoid(z(L))**, cost **C0 = (a(L) - y)^2.**
**Chain rule:** dC0/dw(L) = dz/dw x da/dz x dC0/da
- dC0/da = **2(a(L) - y)**
- da/dz = **sigmoid'(z(L))**
- dz/dw = **a(L-1)** (previous layer's output)
So: **dC0/dw(L) = a(L-1) x sigmoid'(z(L)) x 2(a(L) - y).**
All pieces are known from the **forward pass.** For earlier layers
the formula repeats, with extra weight terms, **recursively in
reverse order.**

**Update rule:** **w <- w - (learning rate) x (gradient).**

### Epoch vs iteration vs update
- **One epoch = whole dataset seen once. It is not one update.**
- Mini-batch: **each batch gets its own forward/backward pass and
  weight update.** 5 batches per epoch = **5 updates** per epoch;
  10 batches = 10 updates; full batch = 1 update.

## Big picture recap
- Neuron = weighted sum + activation (sigmoid neuron = logistic
  regression).
- Layers give non-linearity and **learned, hierarchical features.**
- Train by **forward pass, loss, backprop, gradient step,** over
  epochs of mini-batches.
- Deep learning = best for **unstructured** data; trees for
  **tabular.**

- Structured = tabular (Excel); unstructured = images, text,

  activation.**

  (classification).
- **Epoch:** complete forward and backward pass over all training
  data.
- **Chain rule:** derivative of f(g(x)) = f'(g(x)) x g'(x).
- Parameters: example network = **18 + 56 + 36 = 110.**
- Mini-batch updates: updates per epoch = number of batches.
- Interpretability challenge: "if you don't build the feature, it
  can be hard to understand why the algorithm built it."
