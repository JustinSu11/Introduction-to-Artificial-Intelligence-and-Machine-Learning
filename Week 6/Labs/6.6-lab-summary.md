# 6.6 Lab: TensorFlow & Keras (Fashion MNIST)
*AAI-501 · Week 6 Lab · transcript only (no notebook provided, code not run)*

**One line:** Build a **dense neural network** in **Keras** (functional
API) to classify **Fashion MNIST** images into 10 clothing classes.

**Hook:** **Keras = LEGO for networks.** Each line takes the
previous output and snaps on the next layer.

## Steps (as described)
1. **Data:** Fashion MNIST, 28x28 pixel images, **10 classes**
   (T-shirt/top, sneaker, dress...). Ships with deep learning
   packages.
2. **Normalize:** divide pixels (0-255) by **255** -> 0 to 1
   (neural nets like 0-1 or -1 to 1).
3. **Flatten:** 28x28 -> **784-long 1-D vector** (dense layers
   need 1-D input; applies to any 2-D/3-D image).
4. **Model, functional API** (recommended over **Sequential:** more
   flexible, handles **branches**):
   - `keras.Input(784)`
   - `Dense(128, relu)`
   - `Dense(64, relu)`
   - `Dense(10, softmax)` (10 classes -> softmax)
   - Each line is `x = layer(x)`, then `Model(inputs, outputs)`.
5. **Compile:** optimizer **Adam,** loss
   **sparse_categorical_crossentropy,** metric **accuracy.**
6. **Fit:** x_train, y_train, **10 epochs,** **batch size 32,**
   **validation split 10%.**
7. **Plot** accuracy and loss for train vs validation.

## Key ideas
- **Why sparse_categorical_crossentropy?** labels are **integers**
  (0-9) rather than one-hot vectors. *My addition; the lecture
  just says "familiar parameters."*
- **Result:** training accuracy keeps rising, **validation barely
  improves;** validation loss flat -> **diminishing returns.**
  "We probably could have stopped around **epoch 6**" (early
  stopping, 6.4). Learning curves save time.
