# 2.1 Problem Solving as Search
*AAI-501 · Week 2*

**One line:** If an agent has perfect knowledge of the
world, decision-making becomes **finding a path from
start to goal in a directed graph.**

## Setup: "easy mode"
This week the agent is:
- **Fully observable:** it sees the whole world.
- **Deterministic:** it knows the outcome of each action.

"Perfect knowledge" means it knows:
- where it is at all times
- all the decisions it could make
- the **cost** of each decision
- what each decision leads to
- how to **recognize the goal**

(Harder agents in Module 1: hierarchical modularity,
infinite horizon, bounded rationality, stochastic,
multiple adversaries. Those come later.)

## Directed graph
Two parts:
- **Nodes** (circles) = **states** the agent can be in
  (a location, project progress, anything about the
  agent's progress toward its goal).
- **Edges** (lines with arrows) = **decisions** the
  agent can make from its current state.
  - **Arrows** show direction.
  - **Numbers** on edges = **cost** of that decision.

**Search happens inside the agent's controller (brain).**

## Example: San Diego -> San Francisco
- Start node = San Diego (state can also include gas
  left, time taken).
- Edges: north to Los Angeles (node B, cost 2), east to
  Las Vegas (node D), south to the border (node C).
- Nodes = cities. Edges = roads. Goal = San Francisco.
- Task: find the best combination of node paths.

## Other real-world search problems
| Problem | Nodes | Edges |
|---|---|---|
| GPS navigation | places | roads |
| Web crawling | web pages | hyperlinks |
| Social network recommendations | users | friendships |
| Supply chain / logistics | plant locations | transport routes |
| Game AI (NPC pathfinding) | map positions (X,Y or X,Y,Z) | valid moves (can't walk through buildings) |
| Course prerequisite planning | courses | prerequisite links (start AAI-500 -> AAI-501 -> choices -> graduation) |

## State space
- Each **node = one state space**: a full description of
  the world in a **given configuration.**
- Example state: in Los Angeles, 3/4 tank, 30 min
  elapsed. Another: Silicon Valley, 1/8 tank, 6 hrs.
- The **graph = the collection of all possible state
  spaces** (all possible configurations).
- A state only needs the **part of the world relevant to
  the problem** (not whether the local team won).
- **A state must have enough detail to:**
  1. **Predict the effects of an action**
  2. **Determine whether the goal has been met**

## Example: Rob's coin game
2D grid game. **Goal: collect 4 coins.**

**State space = a vector:**
- X, Y position of Rob
- Fuel level (e.g., 1 to 10)
- 4 Boolean variables: coin 1, coin 2, coin 3, coin 4
  collected?

**Ignored as irrelevant:** shirt color, game's age.

**Walkthrough:**
- Rob at (5,8), fuel 6, has coin 2 only.
- He can move **up, down, right**, but **not left**
  (wall).
- **Down:** (5,7), fuel 5, collects **coin 3.**
- **Up:** (5,9), fuel drops, no new coin.
- Square (4,9) gives more fuel.
- Moving costs fuel. Landing on a fuel square adds fuel.
- **Start** (e.g., (0,0), no coins, full fuel) -> moves
  -> **goal state** = all 4 coins collected.

## Discovering the graph
- Perfect information does **not** mean knowing every
  node at the start (state spaces can be infinite).
- The agent knows its options **after each move.**
  Nodes are **discovered iteratively.**

## Explored nodes and the frontier
- Explored nodes = ones the agent has already thought
  through (e.g., south from San Diego = **dead end at
  the border**).
- **Frontier** = the collection of **next steps** from
  all paths explored so far (e.g., Big Sur -> Monterey).
- **Search algorithms differ in how they choose which
  frontier node to expand next.**

## Two types of search strategy
| Type | Knows about the solution? | Analogy in lecture |
|---|---|---|
| **Uninformed** | Nothing | Robot on an island with no idea where the treasure is |
| **Informed** | Something | Robot with a worn treasure map |

Informed search uses a **heuristic**: a way to measure
how close we are to the goal.

## 4 criteria for judging a strategy
1. **Completeness:** if a solution exists, is it
   guaranteed to be found?
2. **Time:** how long does the search take?
3. **Memory:** how much memory does it need?
4. **Optimality:** does it find the **best** solution
   (lowest cost / quickest)?

## Asymptotic complexity and Big O
- How **time and memory grow as the problem (graph)
  gets bigger.**
- Written in **Big O notation.** From worst to best:
  - **Exponential** (grows fastest)
  - **Polynomial** (e.g., n squared)
  - **Linear** (n)
  - **Sublinear** (e.g., O(log n))
- Analysis focuses on **general themes / subclasses of
  problems**, not specific problems.

## The 7 strategies (next two lectures)
**Uninformed (no solution knowledge):**
1. Breadth-first search (BFS)
2. Depth-first search (DFS)
3. Iterative deepening
4. Lowest-cost-first search (LCFS)

**Informed (some solution knowledge):**
5. Greedy best-first search
6. A* search
7. Depth-first branch and bound
