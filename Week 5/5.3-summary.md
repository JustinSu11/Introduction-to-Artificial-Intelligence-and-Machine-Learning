# LAYER 1: LEARN IT

## The big idea
A fancy model only matters if it **beats a dumb baseline.** So
always compute the simple forecasts first.

**Hook:** benchmarks are the **speed-limit sign:** if your
generative AI can't beat **seasonal naive,** don't ship it.

## 1) The four basic forecasts
| Method | Rule | Good for |
|---|---|---|
| **Mean** | average of all past values | flat series |
| **Naive** | last observed value | financial data (**random walk:** last value is often the best forecast) |
| **Seasonal naive** | last value from the **same season** (next March = last March) | seasonal data |
| **Drift** | line from **first to last** point, extended | trending data (can go up/down, not flat) |

Lecture example: quarterly **beer production** (Hyndman), forecasts
start around 2007.

## 2) Decomposition forecasting
Decompose (5.2), forecast each part, **recombine.**
- **Trend-cycle:** linear regression, moving average, **drift,**
  **ARIMA,** or expert opinion.
- **Seasonal:** assume **no change** -> seasonal naive.
- **Noise:** **ignore.** Forecast = trend + seasonal.
- Example: STL on US retail employment: "looks pretty darn good."

## 3) ARIMA
**ARIMA = AutoRegressive Integrated Moving Average.** Predict from
**past values and past errors.**

| Piece | Meaning | Order |
|---|---|---|
| **AR(p)** | prediction = constant + coefficients x the last **p** values | p = how many steps back |
| **MA(q)** | prediction = constant + coefficients x the last **q forecast errors** | q = how many past errors |
| **I(d)** | **differencing** to make the data stationary | d = times differenced |

- MA here is **not** a rolling mean. It uses **past errors** to
  fine-tune, like **boosting** uses residuals.
- ARIMA = AR terms + MA terms (after differencing).

### Stationarity
**Stationary** = mean and variance **don't change over time.**
- Lecture's nine-panel figure: only **B and G** are stationary.
  Seasonal ones (D, H, I) and trending ones (A, C, E, F, I) are not.
  **Cycles are fine** because they're aperiodic.
- Test: **unit root tests**, e.g. **Augmented Dickey-Fuller (ADF).**

### Differencing
| Type | Do |
|---|---|
| **First-order** | y(t) - y(t-1) |
| **Seasonal** | y(t) - y(t-m) (this March minus last March) |
| **Second-order** | difference the differenced series again |
The number of times = **d**.

### Choosing p, d, q
1. **Automate:** packages find the best values.
2. **By hand:** d from trend + **ADF test;** p and q from **ACF and
   PACF** patterns.
3. **Grid search** across combinations, compare with **AIC / BIC**
   (lowest is best).

## 4) SARIMA (seasonal ARIMA)
Run ARIMA logic **on the seasonal lags** and add: to forecast
March, look at **March last year, March two years ago...**
- Extra terms: seasonal **P, D, Q** and **m** = seasonal period
  (12 monthly, 4 quarterly).
- Example: US retail employment, **seasonal difference, then first
  difference** -> more stationary. Software proposes models; check
  **log likelihood, AIC, AICc, BIC** (**lowest** AIC-type wins).
- Forecasts show **confidence intervals** (range of plausible
  values; not covered).
- **Limitation:** that forecast used 2019 data; **2020 changed
  everything.** Forecasts can't see shocks.

## 5) Exponential smoothing and Holt-Winters
**Idea:** predict from **past observations** with **weights that
decay** the further back.
- Weights: **alpha, alpha(1-alpha), alpha(1-alpha)^2, ...**
- **Past observations are not the same as autocorrelation:** you
  can have values but zero autocorrelation.

**Holt-Winters = triple exponential smoothing,** three parts:
| Part | Symbol | Meaning |
|---|---|---|
| **Level** | l(t) | baseline height of the series |
| **Trend** | b(t) | step up/down per period |
| **Seasonality** | s(t) | repeating pattern |
Each has a **smoothing parameter:** **alpha** (level), **beta**
(trend), **gamma** (seasonal).

How each updates (new = **partly today's data + partly yesterday's
forecast**):
- **Level:** alpha x (today's y **minus the old seasonal**) +
  (1 - alpha) x (yesterday's level + yesterday's trend).
- **Trend:** beta x (change in level) + (1 - beta) x yesterday's
  trend.
- **Seasonal:** gamma x (today's y - level - trend) + (1 - gamma)
  x the seasonal from **one season ago** (index m).
- **Forecast h steps ahead = level + h x trend + seasonal
  (from the last year).** The index **k** just makes sure the
  seasonal value comes from the **final year** of the sample.

**Hook:** like **Bayes:** blend what you **see** (observation)
with what you **expected** (forecast). Accurate data -> trust
observation; noisy data -> lean on the forecast.

## 6) ARIMA vs exponential smoothing
**Try both and compare.** Rules of thumb:
| Prefer | When |
|---|---|
| **ARIMA / SARIMA** | complex correlation, lags, cycles, shocks; **non-stationary** economic data |
| **Exponential smoothing** | **stable seasonal patterns;** you want a **transparent decomposition;** need **ease and speed** |

## Big picture recap
- Baselines first (mean, naive, seasonal naive, drift).
- Decomposition forecasting = forecast parts, recombine.
- **ARIMA(p, d, q)** needs stationarity; **SARIMA** adds seasons.
- **Holt-Winters** = level, trend, season with alpha, beta, gamma.
- Choose by data; compare with accuracy metrics (5.4).

# LAYER 2: QUIZ REFERENCE

- **Mean method**, **naive method**, **seasonal naive**, **drift**
  (drawing a line between the first and last points).
- Naive works well for financial series because of the **random
  walk.**
- Basic forecasts are often used as **benchmarks** ("score to
  beat").
- **ARIMA** = Autoregressive Integrated Moving Average. **AR(p):**
  p past terms. **MA(q):** q past error terms. **d:** degree of
  differencing.
- **Stationary:** mean and variance don't change over time. Tests:
  unit root; **ADF.**
- **First-order**, **seasonal**, **second-order** differencing.
- Selecting orders: automate, ACF/PACF, grid search with **AIC /
  AICc / BIC** ("which is usually the lowest").
- **SARIMA:** seasonal p, d, q + **m** (frequency of seasonality).
- **SARIMA example:** seasonal difference then first difference,
  retail employment, forecast made from 2019 data.
- **Holt-Winters** also called **triple exponential smoothing;**
  components **level, trend, seasonality.**
- **Level** "baseline value or scale at which the series is at."
- **Past observations vs autocorrelation** are different.
- ARIMA when: complex correlation, substantial lags, cycles,
  shocks, non-stationary. Exponential smoothing when: stable
  seasonality, transparent decomposition, ease and speed.
