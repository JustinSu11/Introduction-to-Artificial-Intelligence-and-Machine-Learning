# 5.2 Time Series Decomposition
*AAI-501 · Week 5 · cross-checked against the transcript*

**One line:** **Decomposition** splits a series into **trend +
seasonal + remainder** with an algorithm. **Classical** uses
moving averages (simple, fragile). **STL** uses **LOESS** smoothing
(flexible, robust to outliers).

**Where it fits:** 5.1 showed the three parts by eye. 5.2 computes
them. 5.3 uses them to forecast.

# LAYER 1: LEARN IT

## The big idea
If you can peel the trend and the season off a series, what's left
should be **random noise** (like good regression residuals).

**Hook:** unwrap a gift: **trend** (the box), **seasonal** (the
wrapping pattern that repeats), **remainder** (the loose bits).

## 1) Additive vs multiplicative
| | Additive | Multiplicative |
|---|---|---|
| Formula | **y = T + S + R** | **y = T x S x R** |
| Use when | seasonal swings are about the **same size** | seasonal swings **grow with the trend** |
| Classical rule | subtract | **change every subtract to divide** |

- Multiplicative is common in **economics.**
- Alternative: **transform** (e.g. **log**) until variation is
  stable, then use additive.

## 2) Classical decomposition (4 steps, additive)
Seasonal period **m**: monthly **m = 12**, quarterly **m = 4**.
1. **Trend-cycle** with a **moving average.**
   - **m even -> window 2 x m**; **m odd -> window m** (lecture's
     wording).
2. **Detrend:** y minus trend.
3. **Seasonality:** average the detrended values for each season
   (all Marches, all Aprils...). Then **adjust so they sum to
   zero** (subtract their mean), so seasonality doesn't absorb
   part of the trend's level.
4. **Remainder** = y - trend - seasonal.
- **Multiplicative:** detrend = y / trend; remainder =
  y / (trend x seasonal).

**Trap (zero-sum):** if seasonal values drift up on average, that
offset belongs in the **trend**, not the season.

*My addition: Hyndman's "2 x m-MA" = an m-point moving average
followed by a 2-point one, which centers an even window. The
lecture says "window 2 x m".*

**Three limits of classical decomposition**
1. **No trend estimate at the start or end** of the series (moving
   average needs both sides).
2. Assumes **seasonality doesn't change.**
3. **Not robust to outliers.**
Other methods: **SEATS, X11, STL.**

## 3) LOESS smoothing
**LOESS = Locally Estimated Scatterplot Smoothing.** Fits a smooth
curve through noisy points.

**Pass 1: distance weights**
1. For **each point**, take a **window** of nearby points (e.g.
   100) centered on it.
2. Fit a **weighted linear regression** (weighted least squares).
3. **Center point = highest weight;** farther points = lower
   weights, lowest at the window edge.
4. Read the fitted line's value at that point.
5. Repeat for every point, join them into a smooth curve.

**Pass 2: residual weights (robustness)**
- Refit, but now **the bigger the residual, the smaller the
  weight,** so an outlier barely pulls the curve.
- Repeat distance-then-residual rounds several times.

**Hook:** LOESS = a **rolling local jury** that votes by
closeness, then **ignores the loudest outlier.**

## 4) STL decomposition
**STL = Seasonal-Trend decomposition using LOESS.** Same steps as
classical, but:
| Step | Classical | STL |
|---|---|---|
| Trend-cycle | moving average | **LOESS** |
| Detrend | subtract | subtract |
| Seasonality | straight average per season | **LOESS on the detrended values per season** (can change over time) |
| Repeat | no | **several rounds** of trend and seasonal updates |
| Remainder | y - T - S | y - T - S |

**Comparison (tricky dataset):** STL trend is smoother, seasonal
captures changing amplitude, **remainder amplitude is smaller** and
more normal, and classical shows odd behavior near the end.

**Use STL when:** the seasonal period is **fixed** (you still must
give it) but **seasonality changes** and you want **outlier
robustness.**

## Big picture recap
- Series = parts you can add (or multiply).
- Classical = moving average + seasonal averages; limits: ends,
  fixed season, outliers.
- STL = same plan with LOESS; flexible and robust.
- Know your data first (use the 5.1 plots) and ask experts which
  method is used in your field.

# LAYER 2: QUIZ REFERENCE

- Components: **trend (trend-cycle), seasonal, residual
  (remainder).** Good residual ~ **normal, centered at zero.**
- **Multiplicative** when seasonal magnitude moves **proportionally
  to the trend** (purple series in lecture figure).
- Classical steps (additive): (1) trend-cycle by moving average,
  (2) detrended = y - trend (green line), (3) seasonality =
  average detrended values per season, adjusted to sum to zero,
  (4) remainder = subtract both from original.
- Window rule: **m even -> 2m; m odd -> m.**
- Example in lecture: **US retail employment** (Hyndman).
- Classical limitations: no estimates at ends; constant
  seasonality; poor outlier robustness.
- **LOESS:** locally estimated scatterplot smoothing; data window;
  **distance-weighted least squares** then **residual weights**
  (higher residual, smaller weight); repeat until final curve.
- **STL** advantages: handles seasonal change, outliers; needs a
  fixed seasonal period.
- Other methods named: **SEATS, X11, STL.**

*Lecture slip: at the multiplicative seasonality step the lecturer
