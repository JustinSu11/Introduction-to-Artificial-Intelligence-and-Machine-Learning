**One line:** A **time series** is data in time order. Before any
model, **look at it.** Nine plots show you its **trend, seasonality,

# LAYER 1: LEARN IT

## The big idea
**Time series analysis = understanding AND forecasting data
patterns across time.** Understanding comes first: a forecast
you can't explain isn't useful in business.

**Hook:** a time series is a **song.** Trend = the volume slowly
rising, seasonality = the chorus that repeats, noise = static.

**Three data types** it can be applied to:
1. **Numerical** (beer production, stock price, class attendance).
   *This course focuses here.*
2. **Categorical** (will Sunday be sunny, rainy, cloudy?).
3. **Text** (an LLM forecasts the next word from previous words).

## 1) The three components
| Part | Meaning | Retail example |
|---|---|---|
| **Trend** | long-term change | sales rising 2015-2020 |
| **Seasonality** | repeating pattern at a fixed period | low at start/end of year, high mid-year |
| **Noise** (residual) | what's left, random | leftover wiggle |

- **Residual** here is like the residuals in linear regression.
- **Cycle vs seasonality:** a cycle is a "**trend wiggle**": it
  may or may not repeat and isn't regimented (economic booms and
  busts). **Seasonality is predictable.** If you can reliably
  repeat it, it's seasonality.
- Cycles are often lumped with trend into the **trend-cycle.**
- **Add the three components and you get the original series.**

**Trap:** summer gear peaks every summer (seasonal), but the
economy's ups and downs (cycle) don't come on a calendar.

## 2) The nine visualizations (do them in this order)
| # | Plot | Question it answers |
|---|---|---|
| 1 | **The series itself** | up/down? repeats? noisy? (always start here) |
| 2 | **Histogram** | skewed? centered? outliers? |
| 3 | **Scatter plot** of non-time variables | how do variables relate outside time? |
| 4 | **Rolling means** | smooth to see trend/cycle/season |
| 5 | **Seasonal plot** | how consistent is the season, and does it change? |
| 6 | **Lag plot** | is a point related to its past? |
| 7 | **ACF** | correlation at each lag |
| 8 | **PACF** | direct correlation only |
| 9 | **Residual plots** | what did the model miss? |

### Plot 3: scatter example
Electricity demand vs temperature is **non-linear:** demand rises
when it's cold (heating) **and** when it's above about 15-20 °C
(cooling). Thinking only "vs time" would miss it and **underfit.**

### Plot 4: rolling mean
Slide a window (say 10 points), average, shift by one, repeat.
Smooths the data. **Different window = different story**
(stock example):
| Window | Shows |
|---|---|
| **10 day** | short-term momentum, reversals |
| **50 day** | week-to-month moves (news cycle) |
| **200 day** | primary trend: **bull market** (going up) vs **bear market** (going down) |

### Plot 5: seasonal plot
Chop the series into one season (Jan-Dec) and **overlay** each year.
Retail can have **daily, weekly, monthly, yearly** seasons at once.
Patterns you'll see:
| Pattern | Looks like |
|---|---|
| Stationary seasonality | overlays look alike |
| Strengthening seasonality | **amplitude grows** |
| Non-stationary seasonality | start/end of the season **shifts** (Jan -> Feb) |
| Level shift (our retail data) | same shape, higher each year (trend) |
| Changing shape | weak or unstable seasonality |

### Plots 6-8: lag, ACF, PACF
- **Autocorrelation** = how much a series matches a **lagged copy
  of itself.** **Lag** = shift by k steps.
- Seasonality = a lag with **high autocorrelation** (12 months).
- **Lag plot:** pair each point with the point k steps earlier,
  scatter them. Do lag 1, 2, ... 12.

**Lag-plot shapes**
| Shape | Meaning |
|---|---|
| tight upward line | **positive autocorrelation** (high follows high) |
| downward / bouncing | **negative autocorrelation** (oscillation, regression to the mean) |
| circle / cyclic | **seasonality** |
| random cloud | no autocorrelation at this lag |
| **fan** (spread grows) | variance grows with value: consider a **log transform** |

**ACF plot:** x = lag (0 to 25 in the example), y = correlation of
y(t) with y(t-k). **Lag 0 = perfect (1).**
- **Slow decay** -> trend.
- **Spikes every 12, 24** -> seasonality.
- On **residuals** it should look like **white noise** (about
  zero). Significant spikes = the model left something behind.
- Later used to pick model terms.

**PACF:** correlation between y(t) and y(t-k) **after removing the
in-between lags** (t-k+1 ... t-1).
- **ACF = direct + indirect** effects. **PACF = direct only.**
- Hook: ACF is **all the gossip chain**; PACF is **just person
  to person.**

### Plot 9: residual patterns
| Pattern | Meaning / fix |
|---|---|
| random scatter | **good fit** |
| trend left | model missed trend |
| seasonal swings left | missed seasonality |
| **heteroskedasticity** (variance changes) | maybe a **log transform** |
| outliers | clean or remove |
| autocorrelation | dependence left |
| **funnel** (variance grows) | transform |

## Big picture recap
- Time series = **trend + seasonality + noise** (cycles ride with
  the trend).
- Always **plot first.** Nine plots, simple to quantitative.
- **ACF/PACF** quantify what lag plots show.
- **Residuals** tell you if the model is done.
- Understanding changes (e.g. growing seasonal amplitude) is
  something you can act on in a business.

# LAYER 2: QUIZ REFERENCE

- **Time series analysis** (definition): "both understanding and
  forecasting data patterns across time."
- Recommended text: **Forecasting: Principles and Practice**
  (**Rob Hyndman** and co-authors), R and Python code.
- Lecturer's examples: beer production in Australia, stock price,
  AAI-501 attendance, retail sales 2015-2020 (hypothetical).
- **Cycle** = a trend wiggle; not as regimented or predictable as
  seasonality; **trend-cycle** = trend plus cycle.
- **Decomposition** (next lecture): trend, seasonal, residual.
- Rolling mean windows: **10, 50, 200**; rolling means were used
  for **anomaly detection** (previous module).
- **Stationary** (preview): "think of stationary as simply the
  shift in the mean and variance of a time series" (lecturer's
  loose wording; formal in 5.3).
- Autocorrelation: "how much a time series matches a lagged
  version of itself."
- ACF: lag 0 = perfect; slow decay = trend; regular spikes (12,
  24) = seasonality.
- PACF: removes effect of intermediate lags; **ACF captures
  direct and indirect effects, PACF only direct.**
- Good residual: randomly scattered around zero, no pattern.
- Why EDA first: forecasts aren't helpful if you can't explain
  why; you can proactively address changes (e.g. seasonality
  growth).
